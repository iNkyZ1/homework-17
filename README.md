# homework-17

## Описание

Одностраничное приложение (SPA) для просмотра информации о персонажах, локациях и эпизодах мультсериала **Rick and Morty**.

В этом задании реализована **авторизация пользователя**, а также **защита приватных маршрутов**:

- Доступ к страницам персонажей, локаций и эпизодов возможен **только после входа**
- Реализована **страница входа** (`/login`)
- Есть **кнопка "Выйти"**, которая возвращает пользователя на страницу входа

---

## Технологии

- **Vite**
- **React**
- **TypeScript**
- **React Router v6**
- **Context API**
- **Локальные JSON-данные**

---

## Функциональность

- Главная страница с навигацией
- Страница входа с имитацией авторизации (логин/пароль не проверяются)
- Сохранение состояния авторизации в `localStorage`
- Кнопка "Выйти" в шапке
- Приватные маршруты:
  - Список персонажей и страница персонажа
  - Список локаций и страница локации
  - Список эпизодов и страница эпизода
- Страница 404 при неверном маршруте
- Типизация данных через TypeScript
- Используются project references (`tsconfig.app.json`, `tsconfig.node.json`)

---

## Структура проекта

```bash
src/
  components/     # Компонент PrivateRoute
  contexts/       # Контекст авторизации и хук useAuth
  data/           # Локальные JSON-данные
  layouts/        # Основной layout с навигацией и кнопкой Выйти
  pages/          # Страницы приложения (включая Login)
  types.ts        # Типы данных TypeScript
  main.tsx        # Точка входа с маршрутизацией
```

## Установка и запуск

```bash
npm install

```
